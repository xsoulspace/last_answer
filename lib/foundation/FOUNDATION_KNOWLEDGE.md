# FOUNDATION_KNOWLEDGE.md

**Owns:** the cross-cutting facility layer — `envs.dart` (dart-define
config), `router_paths.dart` (ScreenPaths), extensions (string/context/
value_notifier/go_router/widget), `map_state_notifier.dart` (the ordered-map
ChangeNotifier base), `share_service.dart`, `file_service/` (io/web/mobile
file access), `complex_local_db.dart` + `remote_client.dart` (generic
contracts), `shared_preferences_keys.dart`, `path_utils.dart`, and the
generated asset classes (`generated/` — flutter_gen output, regenerated by
`just gen`).

**Law:** no domain types live here. Anything a domain needs from another
domain does not pass through foundation — it goes to the backend folders.
