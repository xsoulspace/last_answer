# Current Evidence Status

Use this ledger for the weakest true current claim. Historical evidence is provenance unless this file points to it.

## What works (verified)

- **Model / storage**: `DocStatus`, `AnchorSpanModel`, `formatId` (replaces `DocKind`), `parentDocId`, `spanSnapshot`; body files `docs/{id}.json`; lazy `getChildren`; `getById` reads body from file.
- **UI / navigation**: `DocView` back-stack (`_path`), breadcrumbs (`_BreadcrumbBar` with climb-up + collapse), block-level badges (open/collapsed counts), `Discuss` → child node, `Collapse` → archive + climb, `Apply conclusion` (rewrite head from discussion + collapse) — all wired.
- **MCP**: `doc_state`, `doc_discuss_block`, `doc_collapse` (with optional `rewrite`) — all registered in `main.dart`, verified live on macOS.
- **Maestro**: `e2e/maestro/doc_discussion_lifecycle.yaml` (iOS simulator) — flow covers GDD creation, focus, Discuss, child navigation, collapse/reopen, Apply conclusion.
- **UX / AX**: scrollable toolbar (overflow fixed), `tooltip` on Discuss/Ask AI/Apply conclusion, `key` on badge buttons, heading placeholder (`hintText`), `ValueKey` on text fields.
- **Cleanup**: `_climbUp` deletes empty open children (abandoned nodes) and archives collapsed ones; breadcrumb jump uses `_climbUp`.
