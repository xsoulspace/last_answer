# Last Answer v5: endless conversations + native actors + living artifacts on the landed projection law

## Context & positioning law

From Grok (ambient resident actors — invocation is addressing, no sessions), Replit (chat | artifact | preview trinity, attributed edits), Godot (one live document, many projections), ComfyUI (inspectable pipelines), GarageBand (multitrack timelines): **LA is a world where (1) conversations with actors are endless rooms — the only interaction mode; (2) coworkers are ecsai NATIVE actors — no agent process spawned per task: the harness tool loop codes (real fs tools, attributed commits proven live), the scheduler leases, the daemon hosts N loops, brains are palette rungs (one model → many actors, actors differ by persona/memory/grants/species); (3) ACP agents (Codex/claude-code) are KEPT as DESKTOP-ONLY EXTERNAL ACTORS through the seat seam — never the primary lane, never mobile; (4) artifacts are living documents worked on directly, chat docked beside them; (5) content types are installable formats over one kernel — code first, then images/video/audio/books/screenplays/apps/games; (6) tasks are OPTIONAL tools emerging from conversation, never the door.**

## Architecture: integration on what LANDED today (Nov 7)

- **ADR 0138 planes law (accepted)**: realm journal = AUTHORITY (`RealmControlStore`, sha256-chained, `changesSince(byteOffset)`/`watch()`); ecsly World = PROJECTION only; memory = JSONL fog-of-war. Write path UNCONDITIONAL verbatim (clamps deleted — LA adds no write-side limits); size is a read problem (budgeted views + `zoom #id.cN` expansion).
- **LaWorld = LA's projection instance** (no waiting, no invention): fold the journal with `package:append_log` (`LogCursor`/`TailFold`, landed today) into an in-process ecsly `World` via `World.appendRows` (ADR 0006 — motivated verbatim by this consumer shape, 4.6M rows/s); reuse the `ecsly_conversation` component vocabulary (Thread/Beat/Speaker/AddressedTo/ReplyToBeat/BeatModality incl. toolCall/thought/observation/BeatToolCall/ToolResult) and mirror the harness `BeatWorld`/`ConversationProjection` pattern. UI renders via `EcsController` + `EcsWorldSelector`/`EcsScope` aspect-scoped rebuilds + `EcsFixedStepLoop` creature systems (ecsly 0.1.0 STABLE published today — pin the published API contract). Invalidation rides flush boundaries/`EcsInvalidationBatch` (core has no per-component mutation hook). NOT via `ecsly_world_sync` (World→doc only). Mobile: the fold stack is pure Dart — LaWorld runs on-device; journal reads/writes work daemon-free; HTTP `cast:` brains (G6) power actors; heavy file work runs daemon-side actors on desktop/VPS coordinated through the journal (mesh relay later, NORTH_STAR staging). Capability gates via `device_capabilities.dart` — honest named absence.
- **Beat-plane convergence**: the journal IS the beat plane (ADR 0138 D1). LA chat converges onto `DurableConversation` verbs (thread open/say/read/wait/list/close + `inbox.unreadByThread` + `thread_reads` receipts — the plane every seat rides, so rooms are shared with external actors incl. ZCode/Cursor and the ACP bridge). Kernel `DocReplica` keeps its real job: ARTIFACTS (docs/code). Backward paging = query the folded World tail (client-side, fast) — no `beforeBeat` verb needed on the journal plane; the kernel plane gets a tail-slice read fix for the offline lane.
- **Native-actor observability (all durable today)**: journal `durable_tasks` lifecycle + `tool_loop_telemetry` full rows (rounds/toolCalls/tokens/cached/appliedWrites/context-plan — extend LA's lossy projection) + `logs/daemon_actor_loops.jsonl` per-call lines (fold with `plainLineFraming` + TailFold for work-card drilldown) + terminal results/verdicts/spend. `PrefixCacheLedger` is daemon-in-process — UI exposure filed as a surface_gaps ask, not LA-side work.
- **ACP-as-external-actor seam (desktop only)**: mint `ParticipantIdentity` (issuer `la-acp-<agent>`, opaque durable subject = ACP session id — the `codex-thread` precedent), seat grant via `agent_local_seat` (`join` self-admission where allowlisted, else operator `issue`/`admit`), `actor_ensure` the bridge actor (identity precedes binding; external brain never binds a palette cast), then bridge: ACP session updates → `thread say` beats attributed to the actor; addressed beats (`wait addressedToMe`) → ACP prompts; ACP permission requests → inline chat permission cards (0c). The existing `AcpAgentRuntime` (sessions/streaming/permissions) is the transport; LA holds its own `ProfileActorAuthority` in-process (documented for embedded apps like LA, by name).
- **Collision law**: LA edits NEITHER `~/xs/ecsai_harness` NOR `~/xs/ecsly` (convergence program + release train live in both; gaps → `surface_gaps.md` asks). Re-run `pub get` before builds (pubspec churn tonight). Do NOT use: worker-era verbs (delegate/claim/progress/heartbeat/finish — named migration errors), `docId` keying (→ `conversationId`, `rowConversationId()` reads both), write clamps, `context_core_mirror` (deleted). FLAGGED CONFLICT: `ecsly_boards` is harness-declared FROZEN but LA's Boards view adopted it — renegotiate with the harness owner or plan migration (open tail, off critical path).
